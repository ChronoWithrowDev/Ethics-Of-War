# Ethics of War — Windows Desktop Build Kit

This kit wraps the Vite/React game in an Electron desktop window and builds a Windows Setup installer plus a portable executable.

## Build on GitHub

1. Extract this ZIP.
2. Create a new, empty GitHub repository (for example, `Ethics-of-War`).
3. Upload **everything inside the extracted folder** directly into the repository root. Do not upload only the enclosing folder or the ZIP itself.
4. Confirm that `.github`, `electron`, `src`, `package.json`, `vite.config.ts`, and `electron-builder.yml` are visible at the repository root.
5. Commit the files and open the **Actions** tab. The included workflow is `Build Ethics of War Windows Launcher`.
6. When it succeeds, open the run's **Summary** and download the `Ethics-of-War-Windows-Installers` artifact. Extract that artifact ZIP to find the `.exe` files.

The workflow uses `npm install` (not `npm ci`) so the lockfile can be brought into sync with the added Electron packaging dependencies.

## Local development

- `npm install`
- `npm run dev`
- `npm run dist:win` (on a Windows build environment)

## Notes

- The packaged app uses Chromium local storage, so the game's existing browser save data remains stored in the app's user-data profile.
- The game loads PeerJS 1.5.5 from jsDelivr for its peer-to-peer multiplayer handshake. Multiplayer therefore needs an internet connection and access to the PeerJS signalling broker/CDN. The single-player game does not require a separate game server.
- Node.js is bundled inside Electron in the installed app; players do not need to install Node.js separately.
- The Windows `.exe` installers are generated by GitHub Actions; they are not included in this source build kit.
